# 交易审查系统 - 技术文档

> 版本: v2.0 | 更新日期: 2026-06-05 | 技术栈: React 18 + TypeScript + Vite + TailwindCSS + Recharts + zustand + Cloudflare R2

## 一、项目概览

### 1.1 业务定位
交易审查工具，用于记录、统计、可视化股票交易数据。核心功能包括交易记录的增删改查、四张统计分析表、多维度图表可视化、周期统计、Excel 导入导出。

### 1.2 技术架构

```
┌─────────────────────────────────────────────────┐
│                   App.tsx (入口)                  │
├─────────────────────────────────────────────────┤
│              导航栏  │  DataEditor (编辑)          │
│           首页图表区  │  - CRUD弹窗                │
│           (7图表)    │  - ImportModal (图片/文本)  │
│                      │  - ExportExcelModal        │
├─────────────────────────────────────────────────┤
│              stores/ (状态管理)                    │
│   dataStore.ts       headerKeywordsStore.ts      │
├─────────────────────────────────────────────────┤
│            services/ (业务服务层)                   │
│   excelService.ts    cycleStatsService.ts        │
│   r2Service.ts       text-parser.ts              │
├─────────────────────────────────────────────────┤
│         utils/  │  types/  │  hooks/              │
└─────────────────────────────────────────────────┘
```

### 1.3 数据存储
- **持久化**: Cloudflare R2 (JSON 文件存储)
- **本地缓存**: localStorage (图表配置)
- **格式**: 表1-4 分 4 个 JSON 文件 + 1 个 headerKeywords JSON

## 二、四张表数据模型

### 表 1: 交易记录 (TradingRecord[])

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 (UUID) |
| openDate | string | 开单日期 (yyyymmdd) |
| stockName | string | 股票名称 |
| stockCode | string | 股票代码 |
| tradingType | TradingType | 交易类型 (6种枚举) |
| isSystem | YesNo | 是否符合系统 ("是"\|"否") |
| hasMistake | MistakeStatus | 有无重大失误 ("是"\|"否"\|"其他") |
| profitPercent | number | 盈亏 |
| holdDays | number | 持仓天数 |
| hasCycleStats | boolean | 是否已生成周期统计 |
| hasMonthlyStats | boolean | 是否已生成月度统计 |
| cycleId | string? | 关联周期ID |

### 表 2: 全量分析结果 (AnalysisResult)
计算规则: 从表 1 全量聚合，不做按月/按周期分组。
- 系统盈亏比: `isSystem='是'` 所有记录
- 系统无失误盈亏比: `isSystem='是' && hasMistake='否'`
- 系统有失误盈亏比: `isSystem='是' && hasMistake='是'`
- 非系统盈亏比: `isSystem='否'`
- 6 种交易类型盈亏比: 按 tradingType 分别计算
- 聚合盈亏比 (齐飞水底总/转一致): `calculateProfitRatioByMultipleTypes`
- 平均持仓天数: 按系统/非系统 × 盈利/亏损 分别计算

### 表 3: 月度统计 (MonthlyAnalysis[])
计算规则: 从表 1 按月分组 (`openDate.slice(0,6)`)，每组独立计算。
字段与表 2 一一对应 (systemProfitRatio / avgProfitRatio / totalProfit 等)。

### 表 4: 周期统计 (CycleStats)
计算规则: 按 11 种 `CycleStatType`，每 30 条记录生成一个周期。
`matchesStatType` 判定规则:
| 类型 | 条件 |
|------|------|
| 系统 | `isSystem='是'` |
| 系统无失误 | `isSystem='是' && hasMistake='否'` |
| 系统有失误 | `isSystem='是' && hasMistake='是'` |
| 非系统 | `isSystem='否'` |
| 齐飞水底 | `tradingType='齐飞水底'` |
| 齐飞水底三等量 | `tradingType='齐飞水底三等量'` |
| 齐飞前多踩MA | `tradingType='齐飞前多踩MA'` |
| 风险释放平台转一致 | `tradingType='风险释放平台转一致'` |
| 双阳平台转一致 | `tradingType='双阳平台转一致'` |
| 齐飞水底总 | `tradingType ∈ {齐飞水底,齐飞水底三等量,齐飞前多踩MA}` |
| 转一致 | `tradingType ∈ {风险释放平台转一致,双阳平台转一致}` |

## 三、核心计算模块

### 3.1 盈亏比公式 (calculations.ts)

```
calculateProfitRatio(records, isSystem?, hasMistake?) → number | 'N/A'
  - 过滤符合条件的记录
  - 盈利之和 = Σ(profitPercent > 0)
  - 亏损绝对值之和 = Σ|profitPercent < 0|
  - 较大者 ÷ 较小者
  - 盈利大 → 正；亏损大 → 负
  - 亏损=0 → 返回 'N/A'

calculateProfitRatioByType(records, tradingType) → number
  - 同上规则，按单一 tradingType 过滤

calculateProfitRatioByMultipleTypes(records, tradingTypes[]) → number
  - 同上规则，按多 tradingType 并集过滤
```

### 3.2 总盈亏 (calculateTotalProfit)
`Σ(profitPercent)` 对符合条件的记录求和。

### 3.3 平均持仓天数 (calculateAverageHoldDays)
`Σ(holdDays) / count`，保留 2 位小数。

## 五、导入功能

### 5.1 Excel 导入 (excelService.ts)
- `importExcel`: 解析 Workbook → 按 Sheet 名匹配表 1/2/3/4 → 返回 `ParsedTradeData`
- 表 1 映射: `HEADERS_1` 16 列 → `TradingRecord[]`
- 表 2 映射: 14 行 K/V → `AnalysisResult`
- 表 3 映射: 按列解析 → `MonthlyAnalysis[]`
- 表 4 映射: 按列解析 → `Record<CycleStatType, CycleRecord[]>`

### 5.2 图片/文本导入 (ImportModal.tsx)
- OCR: Cloudflare Workers AI (`@cf/llava-hf/llava-1.5-7b-hf`)
- 文本: `parse-text` Worker 服务
- 盈亏重新计算: `(totalSum / negativeAbsSum) * 100`，保留 2 位小数
- 导入结果列表 → 逐条确认 → 写入 store

## 七、状态管理 (zustand)

### dataStore.ts
```
state:
  records: TradingRecord[]          # 表1
  analysis: AnalysisResult         # 表2
  monthlyAnalysis: MonthlyAnalysis[] # 表3
  cycleStats: Record<CycleStatType, CycleRecord[]>  # 表4
  isLoading / error / r2Token
  hasCustomAnalysis / hasCustomMonthly

actions:
  addRecord / updateRecord / deleteRecord
  updateAnalysis / updateMonthlyAnalysis
  updateCycleStats / updateCustomAnalysisField
  saveToR2 / loadFromR2
  importData / clearAllData
```

### headerKeywordsStore.ts
存储 OCR 识别表头的匹配关键词，持久化到 R2。
