## 一、核心计算引擎

所有计算逻辑集中在 `src/utils/calculations.ts`。以下每个函数按签名、前置条件、计算步骤、边界条件、测试用例五个维度说明。

### 1.1 `calculateProfitRatio`

```typescript
function calculateProfitRatio(
  records: TradingRecord[],
  isSystem?: '是' | '否',
  hasMistake?: '是' | '否'
): number | 'N/A'
```

| 维度 | 内容 |
|------|------|
| **前置条件** | records 为 `TradingRecord[]`, isSystem/hasMistake 为合法枚举或 undefined |
| **过滤规则** | `r => (isSystem ? r.isSystem===isSystem : true) && (hasMistake ? r.hasMistake===hasMistake : true)` |
| **计算步骤** | 1. 过滤；2. `profitSum = Σ(r.profitPercent)` 其中 `r.profitPercent > 0`；3. `lossSum = Σ|r.profitPercent|` 其中 `r.profitPercent < 0`；4. 若 `lossSum === 0` → 返回 `'N/A'`；5. `larger = max(profitSum, lossSum)`, `smaller = min(profitSum, lossSum)`；6. `ratio = parseFloat((larger / smaller).toFixed(2))`；7. 若 `profitSum > lossSum` → 正, 否则 → 负 |
| **边界** | 空数组 → `'N/A'`；全盈利无亏损 → `'N/A'`；全亏损无盈利 → `-parseFloat((lossSum/0).toFixed(2))` 实际为 `-Infinity` → 已通过 `lossSum===0` 提前返回避免；单条记录 → 正常计算 |
| **精度** | `toFixed(2)` 保留 2 位小数，`parseFloat` 去除末尾 0 |
| **变更历史** | v1: 仅 `profitSum / lossSum`（无符号）→ v2: 带符号 → v3: 统一较大者÷较小者 |

**测试用例**:

| 输入 | 预期输出 | 说明 |
|------|---------|------|
| `[{profitPercent:10}, {profitPercent:-5}]` | `2.0` | 盈利 10 > 亏损 5, 10/5=2 |
| `[{profitPercent:5}, {profitPercent:-10}]` | `-2.0` | 亏损 10 > 盈利 5, 10/5=-2 |
| `[{profitPercent:10}]` | `'N/A'` | 无亏损 |
| `[{profitPercent:10.123}, {profitPercent:-3.456}]` | `2.93` | 精度保留 2 位 |
| `[]` | `'N/A'` | 空数组 |

### 1.2 `calculateProfitRatioByType`

```typescript
function calculateProfitRatioByType(
  records: TradingRecord[],
  tradingType: string
): number
```

| 维度 | 内容 |
|------|------|
| **前置条件** | tradingType 为合法 `TradingType` 枚举值 |
| **计算步骤** | 1. `filter(r => r.tradingType === tradingType)`；2. 同 `calculateProfitRatio` 步骤 2-7 |
| **与 calculateProfitRatio 差异** | 仅过滤条件不同，计算逻辑完全一致。返回值 **无 `'N/A'`**，无亏损时直接返回 `0` |
| **变更历史** | v2: 从 `profitSum/lossSum` 改为较大者÷较小者带符号（与 `calculateProfitRatio` 统一） |

**测试用例**:

| 输入 | 预期输出 |
|------|---------|
| `records=[{tradingType:"齐飞水底", profitPercent:20}, {tradingType:"齐飞水底", profitPercent:-10}]`, tradingType="齐飞水底" | `2.0` |
| 同上, tradingType="非系统" | `0` (无匹配记录) |

## 二、服务层

### 2.1 `cycleStatsService.ts` — 周期统计生成

```typescript
function generateCycleStats(records: TradingRecord[]): Record<CycleStatType, CycleRecord[]>
```

**计算流程**:
1. 对 11 种 `STAT_TYPES` 逐一处理
2. `filter(records, matchesStatType)` 按 `openDate` 升序排序
3. 每 30 条截取为一个 `CycleRecord`
4. 调用 `calculateProfitRatio(cycleRecords)` 计算该周期盈亏比

**matchesStatType 规则表**:

| 类型 | 判定条件 |
|------|---------|
| 系统 | `isSystem === '是'` |
| 系统无失误 | `isSystem === '是' && hasMistake === '否'` |
| 系统有失误 | `isSystem === '是' && hasMistake === '是'` |
| 非系统 | `isSystem === '否'` |
| 齐飞水底 / 齐飞水底三等量 / 齐飞前多踩MA / 风险释放平台转一致 / 双阳平台转一致 | `tradingType === '对应值'` |
| 齐飞水底总 | `tradingType ∈ {'齐飞水底','齐飞水底三等量','齐飞前多踩MA'}` |
| 转一致 | `tradingType ∈ {'风险释放平台转一致','双阳平台转一致'}` |

**幂等性**: 重复调用覆盖更新，不产生重复周期。

### 2.3 `text-parser.ts` — 文本解析

```typescript
function parseTradeText(text: string): ParsedTradeData[]
```

从 OCR/手动粘贴的文本中提取交易记录。

**持仓天数计算** (v2 修复):

```typescript
const startDate = new Date(
  parseInt(minStr.slice(0, 4)),
  parseInt(minStr.slice(4, 6)) - 1,
  parseInt(minStr.slice(6, 8))
);
const endDate = new Date(/* 同上 */);
const diffTime = endDate.getTime() - startDate.getTime();
holdDays = Math.round(diffTime / (1000 * 60 * 60 * 24)) + 1;
```

> v1 硬编码 31 天导致跨 2 月/长月计算错误。v2 用 `Date` 对象精确计算。

```
  tradingType = '非系统'   (可手动修改)
  hasMistake = '其他'     (可手动修改)
```

**profitPercent onChange 特殊处理**:
```typescript
onChange={(e) => {
  const raw = e.target.value;
  if (raw === '' || raw === '-') {
    setFormData({...formData, profitPercent: null});
    return;
  }
  const num = parseFloat(raw);
  if (isNaN(num)) return; // 忽略中间态
  setFormData({...formData, profitPercent: num});
}}
```

```typescript
profit = (totalSum / negativeAbsSum) * 100;
```

## 四、接口规范

### 4.1 R2 存储 API

所有请求通过 Cloudflare Worker 代理到 R2。

**保存**: `POST {VITE_WORKER_URL}/api/data/save`

```
Content-Type: application/json
Authorization: Bearer {r2Token}

Request:
{
  "records": TradingRecord[],
  "analysis": AnalysisResult,
  "monthlyAnalysis": MonthlyAnalysis[],
  "cycleStats": Record<CycleStatType, CycleRecord[]>
}

Response 200:
{ "success": true }

Response 401:
{ "error": "Unauthorized" }

Response 500:
{ "error": "Storage write failed", "detail": "..." }
```

**加载**: `GET {VITE_WORKER_URL}/api/data/load?token={r2Token}`

```
Response 200:
{
  "records": TradingRecord[],
  "analysis": AnalysisResult,
  "monthlyAnalysis": MonthlyAnalysis[],
  "cycleStats": Record<CycleStatType, CycleRecord[]>
}
```

### 4.2 OCR Worker API

**图片 OCR**: `POST {VITE_WORKER_URL}/api/ocr`

```
Content-Type: multipart/form-data
Body: image (file)

Response 200:
{ "text": "识别到的文本内容" }
```

**文本解析**: `POST {VITE_WORKER_URL}/api/parse-text`

```
Content-Type: application/json
Body: { "text": "要解析的交易文本" }

Response 200:
{ "trades": ParsedTradeData[] }
```
